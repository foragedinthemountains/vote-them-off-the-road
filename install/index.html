Take the jury with you

Add the website to your phone's home screen and open it like an app.

Android (Chrome)

Open this site in Chrome, tap the ⋮ menu, then choose Install app or Add to Home screen. Follow the on-screen confirmation.

iPhone (Safari)

Open this site in Safari, tap Share, then choose Add to Home Screen and tap Add.

Desktop (Chrome or Edge)

Look for the install icon in the address bar or the Install option in the browser menu.

Good to know: This is an installable website, not a separate App Store or Google Play download. You need an internet connection to vote and refresh your Jury XP.
